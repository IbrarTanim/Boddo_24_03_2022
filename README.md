Boddo – Social Media App (Java)
Boddo is a simple social media application built in Java (2022).
The app allows users to connect, share updates, and interact with each other through posts and comments.

✨ Features
User authentication (sign up & login)

Create, edit, and delete posts

Like and comment on posts

User profile management

Real-time feed of posts

🛠 Tech Stack
Language: Java

Frameworks/Libraries: used  Android SDK,  plain Java Swing

Database: [SQLite /Firebase 

Version Control: Git
